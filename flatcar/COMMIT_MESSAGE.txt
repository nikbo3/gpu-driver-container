feat: Add Flatcar 6.12.58 support for NVIDIA driver 580.95.05

BREAKING CHANGE: Only driver 580.95.05 is compatible with Flatcar 6.12.58+

Major Changes:
- Build full .ko modules in chroot environment (no re-linking)
- Skip mkprecompiled packaging (use direct .ko file copying)
- Add download verification and loop device cleanup
- Support only driver 580.95.05 for kernel 6.12.58+

Technical Details:
- Older drivers (535.x, 550.x) fail due to kernel 6.12.58 DRM API changes
- Original approach failed during module re-linking (GLIBC mismatch)
- New approach: Compile fully-linked modules inside chroot
- Modules are linked with correct GLIBC and kernel environment
- Direct installation without re-linking eliminates compatibility issues

File Changes:
- Modified: Dockerfile (added e2fsprogs, updated default driver version)
- Modified: nvidia-driver (full module compilation, no re-linking)
- Added: build-all-drivers.sh (automated build script)
- Added: build-driver.sh (single driver build script)
